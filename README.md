# Security Lab Gallery

Public illustration gallery for my Medium cybersecurity lab series
(Check Point, Sentinel, Wazuh + Suricata, Velociraptor, TheHive + Cortex,
MISP, Zeek, and everything after).

Live at: https://jashan-khaira.github.io/security-lab-gallery/

The site is plain static HTML/CSS/JS. `photos.json` is the gallery manifest,
`photos/` holds the illustrations. New artwork is staged and pushed
automatically — nothing here needs editing by hand.
